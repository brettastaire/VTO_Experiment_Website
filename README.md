# Luma Eyewear VTO Experiment Website

This folder is the GitHub Pages publishing source for the six-frame Luma Eyewear experiment.

## Experimental URLs

After publishing this repository with GitHub Pages, use:

- Picture-only control: `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/?vto=0`
- Picture + VTO treatment: `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/?vto=1`

Both conditions use the same website, six products, product photographs, descriptions, dimensions, fixed price ($149.00), fixed rating (4.9), and product-detail layout. The URL parameter controls whether the Virtual Try-On affordance is shown.

## Products

1. Black Round — 48–21–140 mm
2. Brown Square — 52–17–140 mm
3. Silver Aviator — 54–17–145 mm
4. Rose Cat Eye — 52–17–140 mm
5. Crystal Oval — 53–17–136 mm
6. Burgundy Butterfly — 52–16–140 mm

Measurements are lens width – bridge width – temple length, in millimeters.

## Important

- Do not rename `index.html`, `assets`, or `frames`.
- Upload the contents of this folder to the repository root.
- Keep `.nojekyll` in the repository root.
- Camera access requires HTTPS or localhost.
- GitHub Pages provides HTTPS.
- MediaPipe and its face model load from external HTTPS resources, so internet access is required.
- No participant data, video, or photos should be committed to this repository.
