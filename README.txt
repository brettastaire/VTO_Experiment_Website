# Luma Eyewear VTO Experiment Website

This folder is ready to upload directly to the root of a GitHub repository.

## Experimental URLs

- Picture-only condition: `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/?vto=0`
- Picture + VTO condition: `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/?vto=1`

Both conditions use the same six products, pictures, prices, ratings, dimensions, and product-detail pages. In the VTO condition only, each product card displays a **Virtual Try-On** button. Clicking the button opens the VTO interface directly with that specific frame already selected.

The homepage is divided into **Men's** and **Women's** product sections.

Upload `index.html`, `.nojekyll`, `assets/`, and `frames/` to the repository root, then enable GitHub Pages from `main` and `/(root)`.
